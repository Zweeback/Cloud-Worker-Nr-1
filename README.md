## Alice: Autonomous Web Agent & Gatekeeper

Dieses Projekt beinhaltet "Alice", einen autonomen Web-Agenten und Gatekeeper.
Alice fungiert als zentrale Steuerungseinheit, die Sub-Worker für Live-Monitoring und Web-Scraping koordiniert.

**Kernfunktionen:**
- **Omniscience Database:** Sammelt und speichert Chat-Daten und Metadaten von verschiedenen KIs (z.B. als Ersatz für ein Poe-ähnliches Interface).
- **Ressourcen Management:** Verbindet sich mit Google Drive, um Dokumente (z.B. Baupläne für "3D glasses") zu finden und zu extrahieren.
- **Sub-Worker Koordination:** Erlaubt das Spawnen von neuen Agenten-Tasks über ein modernes Dashboard.
- **Dashboard:** Ein FastAPI-basiertes Control-Panel, das alle Agenten und gesammelten Chats übersichtlich darstellt.

*Hinweis: Der aktuelle Code ist ein Scaffold / Mock, der die strukturelle Architektur für diese Features bereitstellt.*
